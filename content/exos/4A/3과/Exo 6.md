# EXO 6 — 4A 과3
**Thème : Présentation sur les billets de banque coréens**

**I. Le discours formel : 격식체**
1. Aujourd'hui, je vais parler des [[billets de banque|지폐]] coréens.
2. On peut voir des [[images cachées|숨은 그림]] sur tous les [[billets|지폐]].
3. Ces images [[scintillent|반짝이다]] lorsqu'on les expose à la lumière.
4. Ces technologies servent à [[prévenir|방지하다]] la [[fausse monnaie|위조 지폐]].
5. Regardez les [[numéros|숫자]] imprimés sur ce [[billet|지폐]].
6. Veuillez tenir le [[billet|지폐]] face à la lumière pour voir les détails.
7. La [[fausse monnaie|위조 지폐]] représente un problème grave pour l'économie.
8. Ce motif [[scintillant|반짝이다]] est un élément de sécurité unique.
9. Y a-t-il des questions sur les technologies anti-[[contrefaçon|위조 지폐]] ?
10. La [[fausse monnaie|위조 지폐]] est [[prévenue|방지하다]] grâce à ces dispositifs.

**Corrections — I**
1. 오늘은 한국 지폐에 대해 말씀드리겠습니다.
2. 모든 지폐에 숨은 그림이 있습니다.
3. 이 그림들은 빛에 비추면 반짝입니다.
4. 이 기술들은 위조 지폐를 방지하기 위한 것입니다.
5. 이 지폐에 찍힌 숫자를 보십시오.
6. 지폐를 빛에 비추어 세부 사항을 확인해 주십시오.
7. 위조 지폐는 경제에 심각한 문제입니다.
8. 이 반짝이는 무늬는 독특한 보안 요소입니다.
9. 위조 지폐 방지 기술에 대해 질문이 있으십니까?
10. 이 보안 장치들 덕분에 위조 지폐가 방지됩니다.

**II. Expressions pour une présentation (발표)**

*Contexte : vous expliquez les éléments de sécurité des billets coréens.*

1. "Je vais maintenant commencer ma présentation."
2. "Je vais parler des éléments de sécurité des [[billets de banque|지폐]] coréens."
3. "Je vais d'abord présenter l'historique, puis expliquer les caractéristiques de sécurité."
4. "Ce que vous voyez maintenant, c'est une image agrandie d'un billet de 50 000 wons."
5. "Veuillez tenir votre billet face à la lumière pour voir les [[images cachées|숨은 그림]]."

**Corrections — II**
1. 지금부터 발표를 시작하겠습니다.
2. 저는 한국 지폐의 보안 요소에 대해 발표하려고 합니다.
3. 먼저 지폐의 역사를 소개한 다음에 보안 특징에 대해 설명하겠습니다.
4. 지금 보시는 것은 오만 원짜리 지폐의 확대 이미지입니다.
5. 지폐를 빛에 비추어 숨은 그림을 확인해 주십시오.
